# Coaching Institute Admission Enquiry Automation

An automated admission enquiry and lead management system
built using n8n.

## Technologies Used
- n8n
- Google Sheets
- Gmail API
- Docker

## Features
- Student admission enquiry form
- Automatic lead collection
- Google Sheets CRM integration
- Counsellor email notifications
- Student confirmation emails
- 24-hour follow-up reminders
- Lead status tracking
- Conversion rate dashboard

## Workflow
Student Form → n8n → Google Sheets → Gmail Notifications
→ 24-Hour Wait → Follow-up Reminder

## Business Objective
Help coaching institutes automate student enquiry
management and reduce manual administrative work.
